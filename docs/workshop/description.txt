[h1]Main Button Bar System[/h1]

Tidy up the bottom button bar. With many mods it fills up with dozens of squeezed buttons: reorder, hide, rename and resize them, put rarely used ones in a "More" drawer, or let the bar scroll. Until you change something, it looks exactly like the game.

[h2]Features[/h2]
[list]
[*]Drag to reorder; hide, rename, set widths; pin buttons to either end.
[*]Display modes: Vanilla, Collapse ("More" drawer), Scroll, Collapse + scroll.
[*]Text, icon, or both per button; use another button's icon or your own PNG.
[*]Hotkeys for every button. Settings per save, with a default template.
[*]Share arrangements as a file, as text, or as a Workshop-ready mod.
[*]Six built-in themes, custom themes mixed button by button, and "New theme…" to make your own with any image editor (a different picture per button takes a few lines of XML; guide included).
[*]29 languages.
[/list]

[h2]Compatibility[/h2]
[list]
[*]Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]. RimWorld 1.7.
[*]Icon packs and mods that add buttons keep working.
[*]Mods that take over the whole bar (TooManyButtons, Custom Bottom Bar, UI Not Included, DragReorder) are detected and you choose which one draws it. With UI Rethemed - Main Bar, turn off its "Main bar" to use this one.
[*]Removing it from a save logs one harmless "could not find class" message.
[/list]

Settings: Options > Mod Settings > Main Button Bar System, or the gear in the "More" drawer. Modders: see API.md in the mod folder.

Made with vibe coding: designed and tested by NAI, code written by AI (Claude by Anthropic), pictures of Nai made with a local AI image model. License: code MIT, Nai's pictures CC BY-NC-ND 4.0, theme-making material CC0 (see LICENSES.md).

Mod 装到两千个，底部按钮挤成一排看不懂的缩写？你的心情栏已经多了两条：
[list]
[*]按钮挤成缩写 -10
[*]找不到研究按钮 -5

装上本模组：拖动排序、隐藏、改名、调宽度，少用的收进「更多」抽屉，或干脆让整条栏滚动。心情 +15。
没动设置之前，外观和原版一模一样。
[list]
[*]四种显示方式：原版、折叠、滚动、折叠＋滚动。按钮可以钉在两端。
[*]每个按钮可选文字、图标或两者，换成别的按钮的图标或自己的 PNG 都行。
[*]每个按钮都能设快捷键，收进抽屉也照样能按。
[*]设置跟着存档走：每个殖民地一套，这个殖民地没了也不会连累下一个。
[*]排法可以导出成文件、文本，或一键打包成创意工坊模组，分享给其他边缘人。
[*]6 款内置主题（帝国、信条、基因实验室、虚空、星航，以及每个按钮里都有一张萘伊像素图的萘伊主题），可以逐个按钮混搭，也能用「新建主题」自己画一套，比殖民者雕一座雕像还快：按钮框、背景和共用插图改 PNG 就好；每个按钮放不同的图要在 XML 加几行设置，写法见 API.md。
[/list]
需要 Harmony。会接管整条按钮栏的模组（TooManyButtons 等）会被检测到，由你决定谁来画，不用让它们打一架；和 UI Rethemed - Main Bar 一起用时，请关掉它的「Main bar」。
制作方式：vibe coding。设计和实机测试是 NAI，代码由 AI（Anthropic 的 Claude）编写，萘伊的图用本地 AI 生图模型制作。制作过程中没有殖民者受到伤害。
