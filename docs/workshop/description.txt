[h1]Main Button Bar System[/h1]

Take control of the bottom bar. With a big mod list it can hold dozens of buttons squeezed to unreadable widths; this mod lets you reorder, hide, rename and group them, scroll the bar, or tuck rarely used buttons into a "More" drawer, without breaking what other mods do to their buttons.

[b]Nothing changes until you change something.[/b] A fresh install looks exactly like the game; the game keeps drawing the bar until you customise it.

[h2]Features[/h2]
[list]
[*]Reorder by dragging, hide, rename, and set a width per button.
[*]Four display modes: Vanilla, Collapse (a "More" drawer), Scroll (mouse wheel or arrows, the map does not zoom), Collapse + scroll.
[*]Pin buttons to the left or right end; the game menu stays locked at the right unless you unlock it.
[*]Text only, icon only, or icon and text per button; pick another button's icon or import your own PNG (kept outside the mod folder, so updates never delete it).
[*]Label alignment, gap, minimum and default widths, drawer columns and cell width, every value with a Default button. Half-width buttons can take the full width too.
[*]Filter the button list by the mod the buttons come from.
[*]Hotkeys for every button, including ones the game gives none; hidden and drawer buttons keep their keys; conflicts are explained.
[*]Settings are per save, with a default template for new games.
[*]Share arrangements: export with a name as a file or as text for Discord. Before importing you see what fits your game (buttons from mods you lack, a missing theme or icons) and pick which parts to take. One button turns your arrangement into a Workshop-ready mod, PNG icons included.
[*]Themes: the vanilla look by default, plus six built-in themes (five in colours inspired by the expansions: Imperial, Creed, Gene Lab, Void, Starfarer; no expansion needed; and Nai, a pixel-art one with a picture of Nai inside every main button), with previews in the Appearance tab. Nai looks best in the Scroll or Collapse + scroll modes with buttons 120 px or wider; a theme can suggest such a layout, applied only when you press its button.
[*]Custom themes: mix parts of different themes button by button (backgrounds, pictures, label colours, alignment, font size, icon size and position, your own PNGs), then save them as files and load them again.
[*]New theme: one click makes a blank theme mod in your Mods folder. Edit its PNG images with any image editor and the bar updates while the settings window is open; no tools, no restart. Enable it like any mod or upload it to the Workshop. Step-by-step guide: ThemeGuide.md in the mod folder (also in Chinese and Japanese).
[*]Theme mods need only XML and images: whole-image backgrounds, decorations such as a portrait at a corner of the bar, a picture inside each button, label colours per state. A theme template and a generator script ship in the mod's ThemeTemplate folder.
[*]Simple and Advanced views; 29 languages.
[/list]

[h2]Compatibility[/h2]
[list]
[*]Requires [url=https://steamcommunity.com/sharedfiles/filedetails/?id=2009463077]Harmony[/url]. RimWorld 1.7.
[*]Buttons are still drawn by the game, so icon packs (Bradson's Main Button Icons, Vanilla Textures Expanded), replaced windows (Modern History Menu) and added buttons keep working.
[*]Mods that take over the whole bar (TooManyButtons, Custom Bottom Bar, UI Not Included, DragReorder) are detected. You choose who draws the bar; default: the other mod keeps it. Their settings are shown for reference; importing them is experimental.
[*]UI Rethemed - Main Bar also draws the main button bar. With both installed, the mod higher in the mod list draws it; to use this mod's bar, turn off "Main bar" in its settings. The settings window tells you which case you are in.
[*]Works with Better Sliders: this mod draws its own sliders with a number box, so nothing overlaps.
[*]Removing this mod from a save logs one "could not find class" message on the next load; this is harmless.
[/list]

[h2]For modders[/h2]
Five extension points, the built-in features use them too: display modes, themes, compatibility bridges, per-button defaults in XML, and a query API (which buttons are on the bar, where the bar is). Themes, arrangements and icon packs need only XML and images, and any mod can carry them without requiring this one (a race mod can ship its own bar theme). See API.md in the mod folder.

Settings: Options > Mod settings > Main Button Bar System, or the gear in the "More" drawer.

[h1]主按钮栏系统 / 主按鈕列系統[/h1]

[b]简体中文[/b]
自定义游戏底部的主按钮栏：拖动排序、隐藏、改名、调宽度，把少用的按钮收进「更多」抽屉，或让整条栏左右滚动。没改任何设置之前，外观和原版完全一样。
[list]
[*]四种显示方式：原版、折叠、滚动、折叠＋滚动；滚轮滚动时地图不会缩放。
[*]按钮可固定在左端或右端；菜单默认锁定在最右边。
[*]每个按钮可选只显示文字、只显示图标、图标＋文字，可换图标或导入自己的 PNG（存放在模组文件夹外，更新不会被删）。
[*]快捷键：原版没有快捷键的按钮也能设置；隐藏或收进抽屉的按钮快捷键照样有效。
[*]设置跟着存档走，并有新游戏用的默认模板。
[*]分享排法：取名后导出成文件或文本（可贴到 Discord）。导入前会先列出哪些按钮来自你没装的模组、缺少的主题或图标，并可勾选只导入哪几部分。一键做成可上传创意工坊的排序模组，PNG 图标一并打包。
[*]外观标签页与主题：默认为原版外观，另有 6 款内置主题（5 款参考各扩展配色：帝国、信条、基因实验室、虚空、星航，不需要扩展；以及每个主按钮里都有一张萘伊像素图的像素风主题萘伊；萘伊适合滚动或折叠＋滚动模式、按钮宽 120 px 以上，主题可以建议这类版面，按下按钮才会套用）。
[*]按钮列表可以按来源模组筛选；半格按钮也能用完整宽度。
[*]自定义主题：逐个按钮混搭不同主题的部件（背景、插图、文字颜色、对齐、字号、图标大小与位置、自己的 PNG），可存成文件、之后再载入。
[*]新建主题：一键在 Mods 文件夹做出空白主题模组，用任何绘图软件改 PNG，设置窗口开着时按钮栏会马上更新，不需要工具、不用重开游戏；做好后像一般模组一样启用，或上传创意工坊。逐步教学见模组文件夹的 ThemeGuide.zh-CN.md。
[*]只用 XML＋图片就能做主题模组：整张背景图、栏角的立绘等装饰图、每个按钮里的图、各状态的文字颜色。主题模板和生成脚本在模组的 ThemeTemplate 文件夹。
[*]兼容 TooManyButtons、Custom Bottom Bar、UI Not Included、DragReorder：可选择由谁绘制（默认由对方绘制）；导入对方设置为实验性功能。
[*]UI Rethemed - Main Bar 也会绘制主按钮栏，两个都装时由排在前面的模组绘制；要用本模组的按钮栏，请在它的设置里关掉「Main bar」。设置窗口会提示目前的情况。
[*]兼容 Better Sliders：本模组的滑块自行绘制并附数字框，不会被盖住。
[/list]
需要 Harmony。从存档中移除本模组时，下次读档会出现一次「找不到类」的记录，不影响游戏。

制作方式：vibe coding。NAI 负责设计和实机测试，代码、翻译和文档由 AI（Anthropic 的 Claude）编写，萘伊的图用本地 AI 生图模型制作。
