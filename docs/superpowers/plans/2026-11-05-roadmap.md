## 輪次

### 第 10 輪：穩定性、效能、UI Rethemed 提示（PR #14，等本機實機測）

- 圖示快取、例外防護、摺疊溢出、數字框、順序跟著遊戲、每幀配置。
- 只提示的相容定義 `CompatNoticeDef`，內建 [LFS] UI Rethemed - Main Bar。
- 測試清單：`docs/testing/round-10.md`。

### 第 11 輪：資料模型（逐欄位「沒改過」、平分時尊重單顆寬度）

主設計 3.10 的兩項決定，是第 12、13 輪的地基。

1. 每顆按鈕的設定改成每個欄位各自用哨兵表示「沒改過」：沒改過的欄位跟隨模組預設，再跟隨整條列。第一次編輯時不再把模組預設整份複製進去。
2. 讀取時合併成一份生效的設定（不配置記憶體），繪製、設定視窗、查詢 API 都用它。
3. 存檔格式 2 → 3：舊格式讀入時，等於模組預設的欄位改成「沒改過」，其餘保留。匯出的排法、排序積木、相容橋接的匯入也跟著改。
4. 平分寬度時（原版、摺疊＋填滿）尊重單顆寬度：設了寬度的按鈕維持設定值，其餘平分剩下的寬度；剩下的不夠時全部等比例縮小，不溢出。
5. 單顆按鈕加「重設這一顆」；寬度比照圖示模式，加上「N 顆有自己的寬度／全部改回跟隨」。
6. 新的合併規則和版面規則都有單元測試。

### 第 12 輪：自訂主題（一）

規格：`2026-11-05-custom-theme-design.md`。

1. 外觀分頁上方切換「預設主題／自訂主題」；兩種模式都有和按鈕分頁一樣的底部按鈕。
2. 自訂主題：左側按鈕清單（最上面是「所有按鈕」），右上預覽四種狀態，下方可調項目。
3. 這一輪的項目：文字（對齊、字級、三種狀態顏色）、圖示（大小、錨點＋位移）、按鈕背景（四種狀態，從已安裝主題的貼圖挑）。
4. 三層逐項往上找：這顆 → 所有按鈕 → 起點主題 → 原版。每一項都有預設值按鈕。

### 第 13 輪：自訂主題（二）

1. 背景插圖（圖、填法、錨點、透明度、內縮）。
2. 匯入 PNG（`MainButtonBarSystem/Images/`）與選圖視窗。
3. 匯出、載入自訂主題（`MainButtonBarSystem/Themes/<名稱>/`），在預設主題清單裡出現。
4. 複製樣式／貼上樣式。
5. 排序分享帶著自訂主題，缺圖時匯入報告列出。

### 第 14 輪：高度與兩排（不是主推路線）

- 作者 2026-11-05：可以做，但不是主推路線。預設維持原版（一排、列高照原版），放進階。
- 開始前要先問作者：「高度」指整條列的高度，還是單顆的高度；兩排的按鈕怎麼分。
- 要處理照原版列高排版的東西：分頁視窗、檢視面板、世界檢視面板、RimHUD 等（`docs/API.md`〈Limits to know〉）。

### 操作性（評測的 UX 項目，功能補齊後再討論）

- 按鈕清單加搜尋或篩選，以及「移到最前／最後」：74 顆時很難找（HANDOFF 第 8 節也列過）。
- 有改動時按 Esc 或 ✕ 先確認，不直接丟掉。
- 不生效的選項變灰並附一行說明（例如原版模式下的間距、摺疊＋填滿時的預設寬度）。
- 原版、捲動模式下抽屜欄全是「—」：提示要先切到摺疊。
- 抽屜沒有高度上限也不能捲動，小螢幕上可能超出畫面上緣。
- 快捷鍵「清除」後回不到遊戲原本的鍵：加預設值按鈕。
- 只顯示圖示時，沒有說明文字的按鈕沒有 tooltip。
- 長譯文（西班牙文、加泰隆尼亞文、德文等）在設定視窗可能折成兩行。
- 多份具名範本，可以快速切換（例如「戰鬥用」「建設用」）。

### 穩定性與效能（審查留下的低嚴重度項目）

- 本模組自己存的快捷鍵只看停用、不看 Visible。
- `BarLayout.Compute` 每次仍有幾 KB 的配置；設定視窗每個事件重建清單、畫全部 74 列、`Truncate` 沒有快取。
- `CustomIcons.Refresh` 沒有 Destroy 匯入的貼圖，每開一次圖示選擇器洩漏一份。
- 切換語言後，`MainButtonBarAPI.ButtonsOnBar` 留著舊的 Def，直到下一次畫列。
- 主選單開著設定視窗時直接讀檔，預覽中的範本副本會留在那一局。
- 間距總和或固定按鈕已經超過列寬時，中間的按鈕寬度變 0（極端設定）。
- 匯入的數值沒有限制範圍（不會崩潰）。
