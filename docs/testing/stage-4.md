## 這一版做了什麼

### 文字／圖示／兩者、自訂圖示（規格 3.2）

- 進階模式選一顆按鈕，新增「圖示與文字」小節。四種顯示方式：
  - 照遊戲原本的：有圖示就只畫圖示，沒有就只畫文字
  - 只顯示文字
  - 只顯示圖示
  - 圖示＋文字
- 下面一行「圖示：…」，有「選擇…」和「預設值」兩個按鈕。
- 做法：按鈕仍由原版 `DoButton` 畫。本模組只在呼叫它的那一刻暫時換掉 `MainButtonDef.icon`／`iconPath`，畫完就換回來。原版的規則是「`Icon` 有值就畫圖示，沒有就畫文字」。「圖示＋文字」則沿用文字對齊的攔截方式，由本模組在左邊畫圖示、右邊畫文字。
- **選擇圖示**的視窗有兩頁：
  - 「內建」：所有按鈕用到的圖示，加上圖示包模組（新的 `MainButtonIconSetDef`）列出的貼圖。
  - 「匯入的」：圖示資料夾裡的 PNG，下面有「打開資料夾」「重新整理」兩個按鈕。
- 匯入的圖片放在存檔資料夾的 `MainButtonBarSystem/Icons/`，**不放在模組資料夾**，因為 Steam 更新或取消訂閱會清掉模組資料夾（規格 4.4）。圖檔不見時退回原本的圖示，設定畫面會註明。
- 清單的圖示欄、右側標題的圖示，都改成顯示實際會用的圖示。

### TooManyButtons、Custom Bottom Bar 的參考值與匯入（規格 3.7）

- 依規格 7.1 記下的欄位名稱，用反射讀對方的設定。欄位不存在或型別不符就略過，不會報錯。
- 進階模式的單顆按鈕多一節「其他模組對這顆按鈕的設定（僅供參考）」，例如「TooManyButtons：隱藏」「Custom Bottom Bar：寬度 120px」。
- 整條列的相容小節列出對方的整條列設定，並有「匯入 X 的設定」：
  - TooManyButtons：順序、隱藏、在它彈窗裡的變成收進抽屜；有抽屜時顯示方式改成摺疊。
  - Custom Bottom Bar：順序、寬度、間距、填滿、文字對齊、每顆的隱藏／強制顯示／寬度／改名／只顯示文字、自訂圖示（圖檔會複製到本模組的圖示資料夾）；顯示方式改成捲動。
  - 匯入只改視窗裡的工作副本，要按「儲存」才保留。
- 規格 4.14：本模組優先時，TooManyButtons 自己的按鈕預設隱藏。
- **這兩個模組的原始碼在 GitHub 上找不到，你目前也沒有啟用**，所以這一節完全沒驗證過。有人回報再修。

## 步驟

1. 進階模式，選「建築規劃」（有圖示）：
   - 切「只顯示文字」，列上變成文字。
   - 切「圖示＋文字」，左邊圖示、右邊文字；滑鼠移上去時兩者一起往右上移。
   - 切回「照遊戲原本的」。
2. 選一顆沒有圖示的按鈕，「選擇…」→「內建」選一個圖示，列上應該出現那個圖示。按「預設值」恢復。
3. 「選擇…」→「匯入的」→「打開資料夾」，放一張 PNG（例如 64×64），按「重新整理」，選它。之後把檔案刪掉再重開遊戲：按鈕退回原本的圖示，設定畫面有「找不到」的說明。
4. 抽屜裡的按鈕也套用同樣的圖示設定。
5. 試一次發佈流程：在本機執行 `python3 tools/make_release.py <repo 外的資料夾>`，看裡面只有 `About`、`1.7`、`Defs`、`Languages`、`Textures`、`LoadFolders.xml`、`API.md`。
6. 「整條列」選「只顯示文字」：所有按鈕都變成文字。再把某一顆單獨設成「只顯示圖示」，只有它不一樣。按「讓 N 顆…都改成跟這裡」，全部回到跟整條列。
7. 外觀分頁：5 款主題都看得到預覽，選一款後主按鈕列、抽屜、齒輪、箭頭都換色；滑鼠移上、分頁開著、停用的按鈕看得出差別。
8. 模組清單（遊戲內、RimSort）看得到本模組的小圖示。
9. （有裝的話）TooManyButtons／Custom Bottom Bar：參考值有沒有出現、匯入的結果對不對。
