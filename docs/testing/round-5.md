# 第五輪測試清單

分支：`claude/round-5`。處理 `test/stage-3-fixes-results` 分支 `docs/testing/results-stage-3-fixes.md` 回報的問題，加上外觀分頁、主題系統、29 種語言。

## 回報的問題怎麼處理

| 回報 | 處理 |
|---|---|
| 1. 連續勾選做不到，整個視窗被拖走 | 視窗 `draggable = false`，只有標題列（含分頁那一列沒被分頁按鈕佔用的地方）能拖。清單的排序改成只能從 ≡ 把手拖，所以在「顯示」「抽屜」欄按住往下拖就是連續勾選 |
| 2. 撞鍵誤報、警告沒說明 | 改用原版 `KeyPrefsData.ConflictingBindings` 的規則（同分類且 selfConflicting、`checkForConflicts`、`extraConflictTags`、`ignoreConflictsWith`）。本模組自存的快捷鍵在遊戲的之後才處理，所以和任何主按鈕快捷鍵同鍵都照實報。警告改成：列出每一條「分類：名稱」，下面說明撞鍵會怎樣、去哪裡改 |
| 3. 抽屜設定按鈕的文字塞不下 | 改成方形齒輪圖示，滑鼠移上去顯示「主按鈕列設定」。貼圖路徑在 Tuning 的 `behaviour/drawerSettingsIcon`，空的時候用原版的 `TexButton.OpenInspectSettings` |
| 4. 「Drawer」欄標題被切掉 | 欄寬取 Tuning 的最小寬度和標題文字寬度的較大值；欄標題關掉換行 |
| 5. 看不出簡單／進階 | 改用原版的 `TabDrawer` 分頁：簡單、進階、外觀 |
| 6. 「預設值」按鈕沒有變灰 | 原版的停用按鈕看起來和啟用的一樣，所以不能用時自己畫成半透明（Tuning 的 `dimmedAlpha`）。上移、下移、清除快捷鍵、套用範本也一樣 |
| 7. 捲動放得下時沒有箭頭 | 最小寬度下面加一行說明 |
| 8. 診斷沒列 `ButtonTextSubtle` | 加上 `ButtonTextSubtle` 和兩個 `DrawAtlas` |
| 對齊的補畫文字少了滑鼠位移 | 補上，位移量在 Tuning 的 `behaviour/hoverLabelOffset`（原版 2px 往右上）；字型改成明確設定（`behaviour/labelFont`，原版 Small） |

## 新功能

### 外觀分頁和主題

- 「外觀」分頁列出所有主題（本模組內建的，以及其他模組提供的），每個主題一張卡片：名稱、作者／來源模組、說明、預覽。
  - 主題有附預覽圖就顯示圖；沒有就用主題的貼圖畫出「一般、滑鼠移上、按下」三顆按鈕和「更多」。這個預覽不執行遊戲的按鈕程式，主選單也能看。
  - 卡片標題列有「預設值」按鈕，回到原版外觀。
- 主題只要 XML＋圖片，不用寫 C#。`BarAppearanceDef` 的欄位都可以不填，不填就是原版：
  - 按鈕四種狀態（一般、滑鼠移上、按下或分頁開著、停用）的九宮格貼圖
  - 文字顏色、滑鼠移上的文字顏色
  - 整條列的背景、「更多」按鈕、左右箭頭的圖示、抽屜的背景、預覽圖
- 實作：本模組畫主按鈕時，攔截 `Widgets.DrawAtlas`（兩個多載）把 `ButtonSubtleAtlas` 換成主題的貼圖，並在 `ButtonTextSubtle` 換文字顏色。這兩處涵蓋 `ButtonTextSubtle` 的背景和 `DoButton` 停用按鈕那段，所以不用 transpiler。只在本模組畫按鈕的那一刻生效，遊戲其他地方不受影響。
- 主題目前跟著存檔走（和其他設定一樣存在 `BarConfig.appearance`），在主選單選的會存進範本。**這件事使用者還沒決定**，要改成全部存檔共用很容易。
- 給主題作者的範本：`docs/API.md` 第 4 節（資料夾結構、About.xml、Defs、每個欄位不填時的行為、九宮格貼圖的建議尺寸）。
- 目前只有內建的「原版」一個主題。DLC 風格的主題等使用者提供圖片。

### 29 種語言

- 翻譯改成每種語言一個 JSON：`tools/i18n/<語言>.json`，英文是母本。`tools/gen_translations.py` 產生 `Languages/`，並檢查：
  - `{0}` 這類佔位符和英文一致；
  - 沒有英文沒有的 key；
  - 缺的 key 列出來（遊戲會退回英文）。
- 新增的 26 種語言由子代理翻譯：照意思譯成當地遊戲介面的說法，用詞盡量對齊 RimWorld 官方翻譯，欄標題、按鈕保持簡短。
- Def 的名稱和說明（DefInjected）也一起翻譯。

## 步驟

1. 打開設定：上方是原版樣式的三個分頁「簡單／進階／外觀」，選中的分頁和下面的內容連在一起。
2. **拖動視窗**：只有標題列能拖。在清單、右側面板、底部按鈕之間按住拖曳，視窗都不應該動。
3. **連續勾選**：在「抽屜」欄按住左鍵往下拖，經過的格子變成同一個狀態。從 ≡ 把手拖才是排序。
4. **撞鍵**：
   - 「建築規劃」的 Tab 不應該再顯示和除錯選單衝突。
   - Medical Tab 的 M 應該顯示和原版的一條快捷鍵衝突，列出分類和名稱，下面有說明。
5. **抽屜**：只有原版＋本模組、只有一顆按鈕收進抽屜時，右下角是齒輪圖示，滑鼠移上去有提示，點了打開設定。
6. **欄標題**：英文介面下「Drawer」完整顯示，和其他欄標題對齊。
7. **預設值按鈕**：已經是預設值時是半透明的。
8. **外觀分頁**：看得到「原版」主題的卡片和預覽；按卡片可以選。
9. **其他語言**：隨便切幾種語言（例如日文、德文、俄文）看設定畫面，文字是該語言、欄標題沒被切掉、`{0}` 有換成數字。
10. **文字對齊**（上一輪沒測）：選「靠左」，滑鼠移上去時文字也往右上移 2px，和背景、圖示一致。

## 請本機確認

- `Widgets.DrawAtlas(Rect, Texture2D)` 的九宮格怎麼切：四角的大小怎麼算（是不是貼圖寬度的某個比例、會不會被按鈕高度限制），以及兩個多載的關係（2 參數的是不是呼叫 3 參數的）。`docs/API.md` 給主題作者的貼圖建議要照這個寫。
- `TexButton.OpenInspectSettings` 的貼圖路徑，以及它看起來是不是齒輪。不是的話，請找一個原版的齒輪貼圖路徑，填進 `Tuning.xml` 的 `drawerSettingsIcon`。
