## 這輪做了什麼

使用者的目標是做成平台：上層讓別的模組（種族模組、主按鈕列模組）兼容本模組，下層讓玩家做設定檔、載入別人的設定檔。

| 項目 | 內容 |
|---|---|
| 匯出時取名 | 「匯出」的每一項都先開一個視窗：名稱、作者（記住上次的，第一次用 Steam 名稱）、說明。存檔案時檔名就是名稱（重複時加 (2)、(3)）。「匯入」選單顯示「名稱，作者（檔名）」 |

## 步驟

### A. 匯出與匯入（同一份模組清單）

1. 調一份有特色的排法（改名、隱藏、抽屜、換圖示，含一個匯入的 PNG 圖示、選一個主題）。
2. 「匯出」→「存成檔案」：視窗有名稱、作者（預設是 Steam 名稱）、說明。名稱填中文，例如「整齊的列」，儲存。
   - `Exports` 資料夾出現 `整齊的列.xml`，內容有 `<meta>`（name、author、buttons 清單）和 `<config>`。
   - 再存一次同名，檔名變成 `整齊的列 (2).xml`。
3. 「匯入」選單：顯示「整齊的列，作者 xxx（整齊的列.xml）」。最後一項「開啟排序資料夾」能打開資料夾。
4. 選這個檔案，開出報告視窗：
   - 作者、說明、「製作環境：RimWorld 1.7.xxxx，Main Button Bar System 0.9.0」、來源。
   - 「兩邊都有的按鈕」的數字等於目前的按鈕數；沒有黃字。
   - 有設定的部分是勾選的，沒設定的部分是灰的、不勾。
5. 只勾「外觀主題」，匯入：只有主題變了，其他不變。按取消離開設定視窗，再測只勾「按鈕名稱」。
6. 全部勾選匯入，結果和匯出時一樣；按儲存後保留。
7. 「複製成文字」→ 把剪貼簿貼到記事本，看得到 `<meta>`；再「從剪貼簿匯入」，報告的來源寫「剪貼簿」。

### B. 跨模組清單（重點）

1. 用按鈕多的排序（例如 `mbbs_buttons_max_noroe`）調好排法並匯出成檔案。
2. 換成按鈕少的排序（例如只有原版＋本模組），匯入那個檔案：
   - 黃字「你的遊戲沒有、設定會略過的按鈕：N 顆」，下面依模組分組列出 defName，模組名稱正確。
   - 匯入後沒有錯誤，缺少的按鈕不會出現。
3. 反過來：在按鈕少的排序匯出，到按鈕多的排序匯入：
   - 「只有你的遊戲有、保留你的設定」列出多出來的按鈕。
   - 匯入前先替其中一顆多出來的按鈕改名或隱藏；匯入後那顆的設定仍在。
4. 匯入一份舊檔（第八輪以前匯出的，沒有 meta）：報告寫「這份排序沒有記錄製作時的按鈕清單」，可以正常匯入。
5. 如果有主題來自其他模組（例如範例主題包）：匯出後停用那個模組再匯入，報告寫主題沒有安裝、會用原版外觀。

### C. 做成排序模組

1. 「匯出」→「做成排序模組」：名稱填中文、作者填英文。Package ID 自動填成「作者.ArrangementMMddHHmm」之類；改成不合法的值（例如有空格、中文、沒有點）會出現說明，建立按鈕變灰；填一個已安裝模組的 ID（例如 `NAI.MainButtonBarSystem`）會提示已被使用。
2. 建立：跳出訊息，寫出資料夾位置，有「開啟資料夾」。資料夾在遊戲的 Mods 資料夾裡，內容：
   - `About/About.xml`：名稱、作者、Package ID、支援 1.7、相依 Main Button Bar System、說明（附一句用法）。
   - `Defs/MainButtonArrangement.xml`：排序 Def，含 meta。
   - 有用到匯入的 PNG 圖示時：`Textures/<ID>/Icons/*.png` 和 `Defs/MainButtonIcons.xml`，排序裡的圖示路徑指向這裡（不是 `file:`）。
3. 重開遊戲，在模組清單啟用這個模組：0 錯誤；匯入選單出現「排序：名稱（作者）」，匯入後 PNG 圖示正常顯示（暫時把 `Icons` 資料夾裡的原檔移開也一樣，證明用的是模組裡的貼圖）。
4. （可選）用遊戲模組清單的上傳功能試傳到工作坊（設成不公開），之後可刪除。

### D. 範例模組（上層：別的模組附帶內容）

把 `examples/` 裡兩個資料夾複製到 Mods，照 `examples/README.md` 的「What to check」：
1. 本模組＋兩個範例：0 錯誤；外觀分頁有「leaf folk (example)」「ember (example)」，卡片上是各自的模組名稱；匯入選單有「leaf folk layout (example)」；圖示選擇器的內建頁有兩個葉子圖示；摺疊模式下「leaf folk」按鈕一開始在抽屜裡、顯示圖示＋文字。
2. 只啟用 `MBBS_Example_SoftRace`（停用本模組）：0 錯誤，沒有「Could not find type」或 MayRequire 相關訊息；「leaf folk」按鈕出現在原版列上。這一步驗證 API.md 裡標「未驗證」的 `MayRequire` 寫法。
3. 只啟用 `MBBS_Example_ThemePack`（停用本模組）：模組清單提示缺少相依，這是預期行為。

### E. 其他

1. 剪貼簿貼一段含 `Class="..."` 的文字匯入：仍然被擋下（不安全）。
2. 換一種其他語言（例如日文、德文）看匯出視窗和匯入報告：字不會擠出框外。
3. 開發模式啟動，記錄本模組的紅字、黃字。
