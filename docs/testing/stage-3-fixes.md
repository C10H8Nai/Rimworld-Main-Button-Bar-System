# 第三階段修正測試清單

分支：`claude/stage-3-fixes`。修正 `docs/testing/results-stage-1-3.md` 回報的問題（那份報告在 `test/stage-1-3-results` 分支）。

## 這一版改了什麼

| 回報的問題 | 處理 |
|---|---|
| 顯示方式、外觀名稱是英文 | `Languages/*/DefInjected/` 的資料夾改成帶命名空間：`MainButtonBarSystem.BarDisplayModeDef`、`MainButtonBarSystem.BarAppearanceDef` |
| 被右箭頭遮住的按鈕還點得到（例如「任務」） | 滑鼠不在捲動區時，捲動區裡的按鈕一律收不到滑鼠：被遮住的部分不會反白、不會跳提示、也點不到 |
| 「更多（26」被截斷 | 「更多」寬度預設依文字自動決定；也可以在進階手動指定 |
| 文字對齊沒做 | 進階「整條列」新增文字對齊：照遊戲原本的／靠左／置中／靠右。做法見下面「請本機確認」 |
| 每個選項要有「預設值」按鈕 | 整條列和單顆按鈕的每個可調項目旁邊都有「預設值」按鈕；已經是預設值時按鈕是灰的 |
| 勾選欄不能拖過去連續勾 | 「顯示」「抽屜」兩欄改成可按住拖過去連續勾選（和工作分頁一樣） |
| 視窗只有標題附近能拖 | 右側面板、按鈕之間等沒有控制項的地方都能拖動視窗。左邊清單除外，因為在清單上拖曳是排序 |
| 「按钮间距」滑桿右邊「0.000」殘影 | 滑桿改成不用 `Listing_Standard.Slider`，自己畫，沒有附帶的數值文字 |
| 參數寫死在程式裡 | 全部搬到 `Defs/MainButtonBarSystem/Tuning.xml`（`MainButtonBarTuningDef`），程式裡的欄位沒有初始值；單元測試會檢查 XML 有沒有漏填。最小寬度的預設值只剩一個來源（80）。抽屜欄數、抽屜格寬、「更多」寬度、箭頭寬度、滾輪速度都可以在設定畫面調 |
| 主按鈕列高度差 1px | 照原版：上緣在畫面底部往上 35px，按鈕高 36px |

其他：

- 設定資料格式升到 2：沒改過的數值存 `-1`、開關存 `Default`，代表「跟預設值」，讀取時從 Tuning 取值。舊的設定檔可以照常讀：原本的 `True`／`False` 會當成明確指定，數值當成明確指定。
- 圖示來源反查不到、但遊戲能從本體資源載入的（例如「Ideos」），資訊欄顯示「遊戲本體資源」。
- 自訂快捷鍵的觸發條件改成和原版 `KeyBindingDef.KeyDownEvent` 一樣：搜尋框有焦點時不觸發、按著 Command／Win 鍵時不觸發。
- 診斷紀錄改成只在開發模式寫入。

## 步驟

1. 簡中介面打開設定：顯示方式應該是「原版／折叠／滚动／折叠＋滚动」。
2. **捲動模式**，按鈕多到超出畫面：
   - 把一顆按鈕捲到一半被右箭頭蓋住，滑鼠移到箭頭上：那顆按鈕不應該反白或跳提示，點下去是箭頭在動。
   - 露在捲動區裡的那一半照常能點。
3. **摺疊＋捲動**：「更多（N）」完整顯示，括號沒被截斷。進階 →「抽屜」小節把「更多」寬度調小再按「預設值」，應該回到依文字自動。
4. **預設值按鈕**：每個滑桿、勾選、選項群組旁邊都有；改了才能按，按了回到預設。單顆按鈕的顯示、抽屜、名稱、寬度、固定位置、強制顯示也一樣。
5. **連續勾選**：在「抽屜」欄按住左鍵往下拖，經過的格子應該一起變成同一個狀態。
6. **拖動視窗**：在右側面板空白處、底部按鈕之間按住拖曳，視窗應該跟著移動。
7. **文字對齊**：進階 → 整條列 → 文字對齊選「靠左」，按鈕文字應該靠左；只有圖示的按鈕不受影響。
   - VTE、Bradson 的圖示和 TD Enhancement Pack 的研究進度條應該照常。
   - 抽屜裡的按鈕也套用同一個對齊。
8. 「按钮间距」滑桿右邊不應該再有「0.000」。

## 請本機確認

文字對齊的做法：本模組畫按鈕時，攔截 `Widgets.ButtonTextSubtle`，讓它不畫文字，再由本模組依對齊補畫同一段文字（原版截短過的文字照樣用）。所以前提是原版的 `MainButtonWorker.DoButton` 用 `Widgets.ButtonTextSubtle` 畫按鈕文字。

請從遊戲的 Assembly-CSharp.dll 確認，只描述行為就好：

- `MainButtonWorker.DoButton(Rect)`：用什麼畫背景和文字；有圖示時文字怎麼處理；文字太長時怎麼截短；圖示畫在哪裡、多大。
- `Widgets.ButtonTextSubtle`：`textLeftMargin` 怎麼影響文字位置，以及 `Text.Anchor` 設成什麼。

下一階段做「文字／圖示／兩者」和自訂圖示，也需要這兩段的資訊。
