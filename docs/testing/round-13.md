# 第十三輪測試清單：自訂主題（二）＋補測發現的修正＋新功能

分支：`claude/round-13`（從 main 36d9333 開出）。

## 這輪做了什麼

| 項目 | 內容 |
|---|---|
| 補測發現的 4 項 | 一顆按鈕的 `DoButton` 一律丟例外時，只記一筆紅字（之前畫和處理輸入各一筆）；「做成排序模組」的 About.xml 前置項帶 `downloadUrl`（本模組 About 的 `url`）和工作坊連結，範例主題包也補上；日文介面作者名不再被改成大寫（遊戲的格式化會把冒號後第一個字母變大寫，名稱、檔名、packageId、路徑改成原樣帶入）；模組設定頁「總是由本模組繪製底部列（測試用）」只在開發模式或已勾選時顯示 |
| 按鈕清單依來源模組篩選 | 按鈕分頁左上切換鈕右邊多一個下拉選單：「模組：全部」，列出每個來源模組和按鈕數。篩選時拖曳、上移／下移只在列出的按鈕之間移動，其他按鈕位置不變。切到另一個存檔、沒有那個模組的按鈕時自動回到「全部」 |
| 文字大小自訂 | 自訂主題的「字級」多一項「自訂大小」，選了下面出現像素滑桿（`Tuning.xml` 的 `ranges.lookFontSize` 8～40，預設值是遊戲一般字的大小，`barDefaults.lookFontSize` 0），有預設值按鈕 |
| 半格按鈕也用完整寬度 | 按鈕分頁進階「寬度與間距」新增開關（預設關）。開了之後原版模式也改由本模組畫列 |
| 主題的建議版面 | 主題 Def 可以寫 `suggestedLayout`（適合的顯示方式、按鈕寬度、半格按鈕用完整寬度）。外觀分頁選到它、目前設定不符時，卡片下面出現黃色提示和「套用建議版面」按鈕，按了才改；萘伊主題建議捲動或收合＋捲動、120px、半格完整寬度 |
| 自訂主題沿用主題自己的 worker | 自訂模式下，自訂外觀沒改到的部分（列背景、抽屜、更多、箭頭、裝飾、沒改過的按鈕部分）照主題本身的 worker 畫。內建主題都沒有自己的 worker，畫面應該不變 |
| 預覽和實際一致 | 滑鼠移上的預覽改成遊戲的著色（不是加亮）；開啟中沒有專用圖時不加亮；沒設對齊時文字照遊戲的位置（靠左、內縮寬度 15%）；「所有按鈕」的預覽借清單上第一顆有圖示的按鈕顯示圖示；有自訂字級時預覽照著畫 |
| 「所有按鈕」的統計 | 清單第一列顯示「（N 顆有自己的設定）」，選它時多一個「全部 N 顆改回跟隨所有按鈕」 |
| 選色 | 每種文字顏色：色塊、色碼框（`#RRGGBB`，可貼上）、「選色…」開遊戲內建的選色視窗（色輪、色票、RGB／HSV 欄位；色票在 `Tuning.xml` 的 `lookColorPalette`）、R／G／B 滑桿 |
| 圖示大小上限 | 滑桿上限改成按鈕高度（36），超過沒有作用 |
| 選圖視窗 | 按鈕背景和背景插圖的「選擇…」開新視窗：「主題裡的圖」（每款主題的四種按鈕背景和按鈕插圖）、「匯入的」（`…/MainButtonBarSystem/Images/` 的 PNG，附「開啟資料夾」「重新整理」）。當按鈕背景時，大於 72px 的圖有黃框和提示，但可以選 |
| 背景插圖 | 自訂主題新增一節：圖、填法（填滿裁切／完整放入／拉伸）、位置（3×3）、不透明度、內縮，每項有預設值按鈕，逐項往上找（這顆 → 所有按鈕 → 主題自己的插圖） |
| 複製／貼上樣式 | 「重設這個樣式」旁邊有「複製樣式」「貼上樣式」（沒複製過時是灰的），可以從一顆貼到別顆或「所有按鈕」 |
| 存成自訂主題 | 外觀分頁「匯出」選單第一項「存成自訂主題…」（沒有自訂外觀時是灰的）：填名稱、作者、說明後存到 `…/MainButtonBarSystem/Themes/<名稱>/theme.xml`，用到的匯入 PNG 一起複製 |
| 載入自訂主題 | 預設主題清單最後一段「你存的自訂主題」，以及外觀分頁「匯入」選單：點了就把它複製進設定（自訂模式、起點主題、PNG 複製進 `Images/`，檔名相同但內容不同時自動改名）。目前有自訂外觀時先確認。起點主題沒安裝時改用原版並提示 |
| 排序模組帶圖 | 「做成排序模組」時，自訂主題用到的匯入 PNG 複製進模組的 `Textures/<id>/Images/`，參照改成 `tex:` |
| 匯入報告 | 排序帶自訂主題、你又缺它用到的圖時，報告列出缺的圖（黃字），不擋匯入 |
| Nai.json 一致性 | 新增單元測試：`tools/themes/Nai.json` 和 `BarAppearances.xml` 的 `MBBS_Nai` 不一致就失敗 |

## 步驟

### A. 補測發現的 4 項

1. round-10 B.3 的測試模組（`DoButton` 一律丟例外）：開局後 log 只有一筆本模組的紅字。
2. 「做成排序模組」做一個模組，看它的 `About/About.xml`：前置項有 `downloadUrl`（GitHub 網址）；重開遊戲啟用它，log 不再有 `needs to have <downloadUrl>` 黃字。
3. 日文介面：匯入選單和匯入報告的作者名照原樣（`boblin00215`），模組設定頁名稱、packageId 被占用的提示也照原樣。
4. 開發模式關：模組設定頁看不到「總是由本模組繪製底部列」；開發模式開：看得到。勾著的時候關掉開發模式：仍看得到（才能關掉）。

### B. 來源模組篩選

1. 按鈕分頁下拉選單：「全部 (N)」和每個模組（按名稱排序，帶按鈕數）。
2. 選一個有多顆按鈕的模組：清單只剩它的按鈕；原本隱藏的那段也只算它的。
3. 拖曳其中一顆到另一顆前面、用上移／下移：切回「全部」看，只有那顆移動，夾在中間的其他模組按鈕位置不變。
4. 選一個模組後讀另一個沒有那個模組的存檔再開設定：自動回到「全部」。

### C. 文字大小、半格、建議版面

1. 自訂主題「所有按鈕」字級選「自訂大小」，拉到 20：實際列和預覽的字都變大；預設值按鈕回到遊戲字的大小。**看 Waylith 吃不吃 `GUIStyle.fontSize`**：字如果完全沒變，記下來（做法要改）。
2. 單顆按鈕選「中」、所有按鈕是自訂 20：那顆是中。
3. 「半格按鈕也用完整寬度」：有半格按鈕（例如悬赏令、Equal Milking）的排序，打開後它和其他按鈕一樣寬；關回來恢復一半。原版模式、沒動其他設定時也有效。
4. 選萘伊主題、原版顯示方式：卡片下出現黃色提示和「套用建議版面」；滑鼠移到按鈕上，提示列出會改的項目。按下去：顯示方式變捲動、預設和最小寬度 120、半格完整寬度開；提示消失。按鈕分頁每項都有預設值按鈕。
5. 選沒有建議的主題：沒有提示。

### D. 自訂主題：worker、預覽、選色、統計

1. 內建主題各選一次，切到自訂（不改任何東西）：列的樣子和預設主題模式完全一樣。
2. 預覽四格：滑鼠移上那格的框是遊戲的著色；沒設對齊時文字靠左、位置和實際列相同；「所有按鈕」的預覽有圖示。
3. 文字顏色：色碼框貼 `#FF8000` 立刻生效；「選色…」開遊戲的選色視窗，選色後按接受生效；視窗裡「預設」色塊是上一層的顏色。
4. 改三顆按鈕的任一項：「所有按鈕」那列顯示「（3 顆有自己的設定）」；按「全部 3 顆改回跟隨所有按鈕」後清掉。
5. 圖示大小滑桿最大到 36。

### E. 選圖、背景插圖、複製貼上

1. 按鈕背景「選擇…」：主題的圖那頁有每款主題的框和萘伊的按鈕插圖；匯入的那頁空白時有說明。把一張 PNG（例如 128×128）放進 `Images/`，按重新整理：出現；當按鈕背景時有黃框和「大於 72px」提示，仍可選。
2. 背景插圖：所有按鈕選一張圖，填法改「完整放入」、位置選右下、不透明度 50、內縮 4：實際列和預覽都照著畫；萘伊主題時，沒改的欄位跟萘伊自己的插圖設定（例如靠左）。
3. 單顆按鈕不設圖、只改不透明度：用的是主題（或所有按鈕）的圖，只有不透明度變。
4. 刪掉 `Images/` 裡用到的 PNG、重開設定或重讀存檔：那張改用主題自己的圖，log 只一行黃字。
5. 複製一顆的樣式，貼到另一顆和「所有按鈕」：完全一樣；沒複製過時「貼上樣式」是灰的。

### F. 自訂主題存檔、載入

1. 外觀分頁沒有自訂外觀時，「匯出」→「存成自訂主題…」是灰的，滑鼠提示原因。
2. 有自訂外觀（含匯入 PNG）時存成「測試主題」：`Themes/測試主題/theme.xml` 和 PNG 都在；再存一次同名，變成 `測試主題 (2)`。
3. 預設主題清單最後一段出現兩份卡片（名稱、作者、起點主題）；「匯入」選單也有。
4. 刪掉 `Images/` 裡那張 PNG，點卡片：確認視窗（因為目前有自訂外觀）→ 套用；`Images/` 又有那張圖，外觀和存的時候一樣。
5. 在 `Images/` 放一張同名但不同內容的 PNG，再載入：新複製的叫 `名稱 (2).png`，外觀用的是主題資料夾那張。
6. 把 `theme.xml` 的 `baseTheme` 改成不存在的 defName，載入：改用原版並提示一次，沒有紅字。`formatVersion` 改成 99：不會出現在清單（log 一行黃字說略過）。
7. 存檔、讀檔後外觀不變；刪掉整個 `Themes/` 後存檔照樣能用。

### G. 分享排法帶圖

1. 有自訂外觀（含匯入 PNG）時「做成排序模組」：模組的 `Textures/<id>/Images/` 有那些 PNG，排序 Def 裡的參照是 `tex:<id>/Images/...`。
2. 刪掉自己的 `Images/` 那張 PNG，重開遊戲啟用該排序模組，從匯入選單套用：外觀和原本一樣（圖來自排序模組）。
3. 「存成檔案」再匯入到沒有那張 PNG 的環境：報告有黃字列出缺的圖，匯入後那顆用主題自己的圖。

### H. 回歸

1. 沒用自訂主題的存檔：外觀和這輪之前完全一樣（六款內建主題各看一次）。
2. 開發模式 0 紅字；本模組沒有新的黃字（除了上面刻意製造的）。
