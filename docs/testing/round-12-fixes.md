# 第十二輪修正的測試清單

分支：`claude/round-12-fixes`（從 main 開，#13～#16 都已合併）。修第十、十一、十二輪實機測出的問題，結果見 `test/round-12-results` 的 `docs/testing/results-round-11.md`、`results-round-12.md`。存檔格式不變（3）。新增 6 個字串，改了 3 個，29 種語言都有。

## 這輪改了什麼

| 項目 | 內容 |
|---|---|
| TooManyButtons 順序 | 本模組優先時，相容橋接除了還原每顆按鈕的 `order`，也把遊戲的按鈕清單排回載入時的順序（TooManyButtons 用不穩定排序重排過，`order` 相同的按鈕在之後的局會對調） |
| 來源模組名稱（F.2） | 本體和 DLC 的名稱改從目前語言的 `ExpansionDef` 取，切換語言後不會停在上一個語言 |
| 匯入報告 | 匯入的排法有自訂主題時，「主題：…」下面多一行「上面還有自訂主題（N 顆按鈕有自己的樣式）」 |
| UI Rethemed - Main Bar（G4、G5） | 三種情況各一句：本模組還沒有設定所以讓給它畫（新）；它排在前面、正在畫；兩邊都開、由本模組畫（寫明右下角的時間控制、日期、天氣會消失）。後兩種旁邊有「關掉 Main bar」按鈕：直接把它的設定改成關並存檔，它每一幀都讀這個開關，所以不用重開 |
| 日文被切 | 設定視窗底部按鈕的文字放不下時改用小字；自訂主題預覽下的狀態名稱、各段標題放不下時換行，高度跟著文字 |
| 平分時太窄的按鈕（C.4） | 寬度小於 `contentMinButtonWidth`（20）的按鈕只畫背景，不畫圖示和文字；被單顆寬度擠壓時，「更多」和選單按鈕至少保留自己的寬度（`splitMoreMinWidth`、`splitMenuMinWidth`，0＝照它們的文字寬度），其他按鈕再分剩下的 |
| 開發模式的主題檢查 | `buttonImages` 指到沒載入的按鈕時，每款主題合併成一條黃字（以前每顆一條）。為了之後的像素通用主題（每顆主按鈕一張圖，會列很多其他模組的按鈕） |
| 改圖示大小或位置時保留文字（規格 4.9） | 圖示模式「預設」的按鈕改了圖示大小或位置後，文字要不要顯示照原本的樣子：原版只畫圖示的照樣只畫圖示；Vanilla Textures Expanded 會加文字的（例如建築規劃）照樣有文字，只是圖示照設定的大小和位置 |

## 步驟

排序都用第十二輪那幾份（`RimCrow\backups\other\ModsConfig_20261105_1631_mbbs_r12_*.xml`、`ModsConfig_20261105_1101_mbbs_r10_mbbs_first.xml`）。先確認 log 有本模組的 `Loaded.`、沒有 `TypeLoadException`（這是本機第一次編譯的 DLL）。

### A. TooManyButtons 順序

1. `r12_base`（有 TooManyButtons，本模組優先）：讀 `MBBS_r12_imperial`，記下「Equal Milking → 求醫者」「经商管理 → 悬赏令」的順序。
2. 回主選單，讀 `MBBS_r12_nai`（或開新局）：兩對的順序和第 1 步一樣（以前會對調）。

### B. 來源模組名稱（F.2）

1. 簡中進遊戲，設定視窗的「來源模組」欄：核心、生物技术等是中文。
2. 切到英文、再切到日文，每次都看同一欄：Core／Biotech、日文名稱，不會停在上一個語言。

### C. 匯入報告

1. 用 `r12_custom_file`（第十二輪匯出的，有自訂主題）匯入：報告在「主题：萘伊」下面多一行自訂主題。

### D. UI Rethemed - Main Bar

1. `mbbs_first`（9 個，本模組在前）、Main bar 開、讀 `MBBS_r10_G`（本模組沒有設定）：黃字是新的「本模組還沒有任何設定…」那句，沒有按鈕。
2. 同一局，在視窗裡選帝國：黃字換成「Main bar 也開著…右下角的時間控制、日期和天氣會消失…」，旁邊有「關掉 Main bar」。
3. 按下去：上方出現「已改好…」的訊息、黃字消失，右下角的時間控制、日期、天氣馬上回來（不用重開）。看它的設定檔 `Mod_3826865706_*.xml` 的 `mainButtons` 是 False。
4. 換 UI Rethemed 排在前面的排序（第十輪 G1～G3 那份）、Main bar 開：黃字是「…排在本模組前面，正在畫底部列…」，旁邊也有按鈕。
5. 測完把 UI Rethemed 的設定檔從備份放回。

### E. 日文

1. 遊戲中打開設定視窗：底部「デフォルトテンプレートとして保存」「デフォルトテンプレートを適用」完整（字可能變小）。
2. 自訂主題：預覽下的「マウスオーバー」「開いているとき」完整（可能換行）；「アイコンの位置」那段說明完整（兩行）。

### F. 平分時太窄的按鈕（C.4）

1. 收合模式、填滿畫面，五顆按鈕設 400（同第十一輪 C.4）：窄的按鈕只有背景，沒有圖示疊在一起；「更多 (N)」整個字看得到；選單按鈕的字看得到。
2. 把單顆寬度清掉：列回到平均分配，和以前一樣。

### G. 改圖示位置時保留文字

1. 有 Vanilla Textures Expanded 的排序，自訂主題「所有按鈕」只改圖示位置：建築規劃仍是圖示＋文字，圖示在選的位置；原本只有圖示的按鈕仍只有圖示。
2. 預覽照遊戲本身的畫法（只有圖示），畫面上的說明寫了這件事。

### H. log

1. 每次啟動本模組 0 紅字、0 黃字。

### I. 主題的按鈕底圖指到沒載入的按鈕

1. 開發模式，另外放一個只用來測試的主題模組（不進 repo），`buttonImages` 列 3 顆不存在的 defName：log 只有一條黃字，列出這 3 顆。
2. 外觀分頁按「重新載入主題貼圖」：不會再多出同一條。
