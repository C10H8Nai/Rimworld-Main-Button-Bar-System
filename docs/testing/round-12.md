# 第十二輪測試清單：預設主題與自訂主題（一）

分支：`claude/round-12-custom-theme`（從 `claude/round-11-data-model` 往下開；#14、#15 合併後，PR 只會顯示這一輪）。存檔格式不變（3），新欄位舊存檔讀進來是「沒用自訂主題」。新增 37 個字串，29 種語言都有。

設計：`docs/superpowers/specs/2026-11-05-custom-theme-design.md`（在 #13）。這輪是第一部分：文字、圖示、按鈕背景（從已安裝主題挑）。背景插圖、匯入 PNG、匯出與載入自訂主題、複製／貼上樣式是下一輪。

## 步驟

### A. 沒用自訂主題時完全不變（最重要）

1. 讀一個用預設主題的存檔（原版、帝國、萘伊各一次）：列和以前一樣（截圖比對），開發模式 0 紅字。
2. 外觀分頁：上方有切換，卡片照舊；右下有底部按鈕，能直接按「儲存」。
3. 只顯示圖示、圖示＋文字、文字靠左等既有設定的按鈕，圖示和文字的位置和以前一樣。

### B. 自訂主題

1. 預設主題選「帝國」，切到「自訂主題」：清單最上面是「所有按鈕」，預覽是帝國的樣子。
2. 「所有按鈕」：
   - 文字顏色改成黃色：列上所有按鈕的文字變黃。滑鼠移上、開啟中沒改時，主題自己有那個狀態的顏色就用主題的，沒有才跟一般的黃色（規格 4.5：每一項先往上一層找，最後才換狀態）。
   - 只改字級（例如「大」）、不改對齊：文字照遊戲的位置（靠左、左邊留一段），只是字變大。再改對齊成靠左：照設定。
   - 按鈕背景的「一般」改成星航的一般背景：所有按鈕換框；滑鼠移上、開啟中、停用的框，主題自己有就用主題的，沒有才用剛選的一般框（加上遊戲的亮起效果）。
   - 圖示位置選「上」「下」各一次（大小 32）：上在置中上面、下在置中下面，都不超出按鈕。
3. 選一顆按鈕（例如「建築」）：
   - 文字顏色改成紅色：只有它是紅的，其他仍是黃的。清單上它標「（已修改）」。
   - 圖示位置選左上、大小 20：只有它的圖示在左上（若它原本是文字按鈕，先在按鈕分頁把它設成「只顯示圖示」或「圖示＋文字」）。
   - 「圖示＋文字」的按鈕選右邊的位置：圖示在文字右邊。
   - 按「重設這個樣式」：它回到跟「所有按鈕」。
4. 每一項的「預設值」按鈕：按了只回到上一層，其他項不變。
5. 預覽：四格分別是一般、滑鼠移上、開啟中、停用，和實際列上的樣子一致；停用那格沒有文字（遊戲也不畫）。
6. 切回「預設主題」：列回到帝國原樣。再切回「自訂主題」：剛才的修改都還在。
7. 在預設主題改選「萘伊」再切回自訂主題：自訂的修改疊在萘伊上面。
8. 按「取消」：所有改動還原；按「儲存」再讀檔：自訂主題保留。
9. 換成英文、日文看一次：切換鈕、各項標籤不擠出框外。

### C. 承上（其他模組）

1. 有 Vanilla Textures Expanded 時：沒改圖示外觀的按鈕照 VTE 的方式畫；改了圖示大小或位置的按鈕照本模組的方式畫。
2. 停用狀態（組商隊 → 選擇路線）：按鈕背景用「停用」那一格的設定；沒設時跟「一般」。
3. 抽屜裡的按鈕也套用自訂主題；「更多」和捲動箭頭照預設主題（不受自訂影響）。

### D. 匯入／匯出

1. 匯出排法（存成檔案），在另一個存檔匯入、只勾「外觀主題」：自訂主題一起帶過去。
2. 主選單編輯範本時也能用自訂主題，新遊戲套用範本後一樣。
