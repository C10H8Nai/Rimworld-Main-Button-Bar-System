# 第十一輪測試清單：資料模型（逐欄位「沒改過」、平分時尊重單顆寬度）

分支：`claude/round-11-data-model`（從 `claude/round-10-fixes` 往下開；第十輪合併後，PR 只會顯示這一輪的改動）。存檔格式 2 → 3。新增 3 個字串，29 種語言都有。

依據：主設計文件 3.10、`docs/superpowers/plans/2026-11-05-roadmap.md` 第 11 輪。

## 這輪做了什麼

| 項目 | 內容 |
|---|---|
| 每個欄位各自「沒改過」 | 每顆按鈕的設定（隱藏、抽屜、名稱、寬度、固定位置、強制顯示、圖示模式、圖示）各自記「有沒有改過」。沒改過的欄位跟著繼承的值：執行期預設（例如相容橋接設的）→ 按鈕所屬模組在 XML 宣告的預設 → 遊戲原本的樣子。以前第一次改某顆按鈕時，會把模組預設整份複製進去，之後模組預設改了，那顆按鈕的其他欄位也不會跟著變 |
| 改成等於繼承值＝沒改過 | 例如把一顆模組預設在抽屜裡的按鈕，取消勾再勾回來：存的是「沒改過」，不是「勾選」 |
| 存檔格式 3 | 存檔、預設範本、匯出的檔案、剪貼簿文字、排序模組（Def）只要是舊格式，讀進來時都會轉換：和繼承值一樣的欄位當成沒改過，其他保留。看起來應該完全一樣 |
| 平分時尊重單顆寬度 | 原版模式、摺疊模式（開著填滿畫面）以前會忽略單顆寬度。現在設了寬度的按鈕維持設定值，其他按鈕平分剩下的寬度；剩下的分到每顆不到 `Tuning.xml` 的 `splitMinButtonWidth`（12px）時，全部等比例縮小，不會超出畫面 |
| 重設這一顆 | 選一顆按鈕時，資訊下方多一顆「重設這一顆」：這顆按鈕的每一項都回到繼承的值（快捷鍵不受影響）。沒改過時是灰的 |
| 寬度全部改回跟隨 | 進階「整條列」的預設寬度下方：有按鈕設了自己的寬度時，出現「讓 N 顆有自己寬度的按鈕都改成跟整條列」，和圖示模式那顆一樣 |

## 步驟

### A. 舊存檔、舊檔案（最重要）

先用 **main 或第十輪** 的版本準備資料，再切到這個分支讀：
1. 一個有改過很多按鈕的存檔（改名、隱藏、抽屜、固定左右、寬度、圖示模式、自訂圖示都要有）。
2. 主選單存一份預設範本（同樣改過幾顆）。
3. 「匯出」→ 存成檔案，以及「複製成文字」存到記事本。

切到這個分支後：
1. 讀那個存檔：列的樣子、設定視窗裡每顆按鈕的值都和之前一樣。開發模式 0 紅字。
2. 存檔後用文字編輯器打開存檔，找 `MainButtonBarSystem` 的 `config`：`formatVersion` 是 3；`overrides` 裡每顆按鈕只列出改過的欄位。
3. 開新遊戲：用的是那份預設範本，樣子和之前一樣。
4. 匯入舊的檔案和剪貼簿文字：報告和結果都和之前一樣。
5. 範例模組 `examples/MBBS_Example_SoftRace` 的排序（舊格式 2）：匯入後「leaf folk」在抽屜裡，其他照舊。

### B. 跟著模組預設走（新行為）

用 `examples/MBBS_Example_SoftRace`（它的 `MainButtons.xml` 宣告「leaf folk」按鈕預設在抽屜裡、顯示圖示＋文字）：
1. 摺疊模式下，只把「leaf folk」改名，儲存。它仍在抽屜裡、仍是圖示＋文字。
2. 關遊戲，把範例的 `MainButtons.xml` 改成 `<inDrawer>false</inDrawer>`，重開讀檔：「leaf folk」**跟著**移出抽屜（以前會卡在抽屜裡），名字還是改過的。
3. 把它的「收進抽屜」取消再勾回：存檔裡這顆按鈕不會出現 `inDrawer`。
4. 按「重設這一顆」：名字回到原本，其他也回到模組預設；按鈕變灰。快捷鍵沒有被清掉。

### C. 平分時尊重單顆寬度

1. 原版模式，進階選一顆按鈕把寬度設成 200：那顆是 200px，其他按鈕平分剩下的寬度，整條列剛好填滿畫面。
2. 再設一顆半寬的按鈕（例如原版的「選單」以外會是半格的按鈕，沒有就略過）：半格的仍是一般的一半。
3. 摺疊模式、開著填滿畫面：同樣尊重單顆寬度，「更多」和菜单也跟著分剩下的寬度。
4. 把好幾顆寬度設得很大（例如 5 顆都 400）：全部按比例縮小，沒有按鈕跑出畫面、「更多」和菜单都看得到也點得到。
5. 「整條列」→ 預設寬度下方出現「讓 N 顆有自己寬度的按鈕都改成跟整條列」，按下後都回到平分。
6. 捲動模式、摺疊（關閉填滿）照舊。

### D. 回歸

1. TooManyButtons 選「本模組優先」：它自己的按鈕一開始仍是隱藏的（執行期預設）。
2. Custom Bottom Bar 的「匯入對方設定」照舊（隱藏、寬度、名稱、圖示）。
3. 匯入時只勾一部分（例如只勾「大小與對齊」）：只有那部分變了；檔案沒提到的按鈕維持你自己的設定。
4. 四種顯示方式、改名、隱藏、抽屜、固定、圖示模式都正常。
